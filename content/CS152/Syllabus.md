## CS152 - Compiler Design

### Overview

CS 152 is a course that will guide you through the key elements of a compiler as well as instruct you how to build one. We will not cover every detail and you are highly encouraged to pursue knowledge beyond what is offered in the class. However, by the end of the quarter you should be able to understand how compilers work and make educated decisions when choosing one or applying optimizations to your code's compilation.

### Catalogue Description

**CS 152 c**overs the fundamentals of compiler design. Includes lexical analysis, parsing, semantic analysis, compile-time memory organization, run-time memory organization, code generation, and compiler portability issues.

### Topics

Each week we will try to cover the content equivalent to a chapter of the book _Compiler Construction Principles:_

1. Introduction
2. Lexical Analysis
3. Context-Free Grammar and Parsing
4. Top-down Parsing
5. Bottom-up Parsing
6. Semantic Analysis
7. Run-Time Environments
8. Code Generation
9. Compiler Backend
