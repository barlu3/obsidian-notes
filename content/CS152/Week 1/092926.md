$$
 \underbrace{\text{Lexical Analysis} \rightarrow_{\text{token stream}} \text{Parsing}}_{\text{Front End}} \rightarrow_{\text{abstract syntax tree}} \underbrace{\text{Intermediate Code Generation}}_{\text{Middle End}} \rightarrow_{\text{intermediate code}} \underbrace{\text{Code Genereation}}_{\text{Back End}} 
$$
Input into Lexical Analysis the Source Code as a character stream (string). Output from Code Generation as Assembly Code equivalent (or target code, not necessarily .s).

### Compilation and Execution

$$
\text{Compiler }_{\text{source code}} \to_{\text{Assembly Code}} \text{Assembler} \to_{\text{Object Code}} \text{Linker} \to_{\text{Machine Code}} \text{Loader}^{\text{Executable Image}}
$$

Linker takes in Library Code and links it with relative files. Loader outputs an executable image from linked Object code (\*.o).
