### Compilation and Execution

$$
\text{Compiler }_{\text{source code}} \to_{\text{Assembly Code}} \text{Assembler} \to_{\text{Object Code}} \text{Linker} \to_{\text{Machine Code}} \text{Loader}^{\text{Executable Image}}
$$

Linker takes in Library Code and links it with relative files. Loader outputs an executable image from linked Object code (\*.o).

### Compilation in a Nutshell

#### Lexical Analysis

Take the character stream (source code) into tokens; data type representing "chunks" of text:
- identifiers: a yll elsex \_100 
- keywords: if else while
- integers: 2 200 -500
- floating point: 2.0 3.2 0.9
- symbols: + \* - / %
- strings: "Hello"
- comments: //comment

##### Scanning

The basic idea is to divide the char stream into tokens with their respective categories.
