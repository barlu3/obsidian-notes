## Parsing

### Top-Down Parsing
*derive* a parse tree from the starting expression

We can try backtracking parsers
- try al different possibilities
- back up arbitrary number of inputer symbols once a try fails
	- way too expensive

Predictive Parsers
- lookahead one or more tokens to narrow down the possibilities
- Table-driven parsers
	- non-terminal derivation encoded in a table
	- most commonly used to implement predictive parsing
	- much more efficient than recursive

Recursive-descent parsing
- comprised of mutually recursive methods
- each method implements a non-terminal

#### Recursive-descent parsing
*Basic idea:* for each nonterminal, define a function to recognize it


### Bottom-Up Parsing
*reduce* a parse tree bottom up from the leaf nodes
