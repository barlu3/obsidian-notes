## What is a Compiler, formally?

### Program that translates from one programming language to another

- high-level to low-level machine code (object code, .obj)
- Clang, GCC, Javac, .NET, V8, etc.

### How does a Compiler work?

#### Translation Strategies:

 - Ahead-of-Time Compilation: An AoT compiler translates a program into an executable (GCC)
 - Interpretation: An interpreter reads a program and produces the results by executing that program (old CPython)
	 - support dynamic features with *portability*
	 - slower and less reliable
 - Just-inTime Compilation: A JIT compiler combines AoT compilation and interpretation (JVM)

### Source Code

#### Optimized for human readability

- *Expressive* : matches human grammar / syntax / meaning
- *Redundant* : more information than needed
	- ensures correct typing (writing acc = 1 vs. *int* acc = 1 or *double* acc = 1)
- *Abstract* : exact computation on CPU possibly not fully determined by code

### Correct Compilation

#### Compilers must be correct!

- Broken compilers generate broken code
- Hard to debug source programs if the compiler is incorrect
- Failure has dire consequences for dev cost, security, etc.
