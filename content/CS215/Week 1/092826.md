### Turing Machines

_Definition_: We say that a TM $M$ <u>computes</u> a function $f : \{ 0,1 \}^* \to \{ 0,1 \}^*$ if whenever a string $x \in  \{ 0,1 \}^*$ is written on the input tape, and $M$ is placed in the starting configuration, eventually $M$ will reach the halt tape with $f(x)$ written on its output tape. 
### TMs with Large Alphabets

$$
\text{Let M be a TM with alphabet } \{ 0, 1, 2, 3, \delta, \gamma \}
$$
Then, we can use an original TM with binary alphabet to represent M; transpose M's alphabet to binary 
$$
\{ 0, 1, 2, 3, \delta, \gamma \}_{M} \equiv \{ 00, 01, 10, 11, 101, 110 \}_{M^{'}}
$$
Formally,

_Theorem_: Suppose a function $f: \{ 0,1 \}^* \to \{ 0,1 \}^*$ is computed by a TM $M$ who uses the alphabet $\{ 0,1,2,\dots,k, \triangle, \square \}$. Then, there exists another TM $M^{'}$ which also computes $f$ but which uses the standard alphabet $\{ 0,1,\triangle, \square \}$. Moreover, if $M$ runs in time $T_{m}(n)$ on inputs of size $n$ , then $M^{'}$ runs in time at most $O(T_{M}(n) * \log(k))$ 

### TMs with Many Work Tapes
$$
 \text{Let M be a TM with work tapes } \{ a, a, a, a \} \text{ and } \{ b, b, b, b \} 
$$
We can fit both work tapes onto a single work tape and map onto the single tape with prime and double prime pointers. Therefore, TMs with multiple work tapes do not add computation power.

We can also define the theorem:

_Theorem_: Suppose a function $f: \{ 0,1 \}^* \to \{ 0,1 \}^*$ is computed by a TM $M$ with $W$ work tapes and who uses the alphabet $\{ 0,1,2,\dots,k, \triangle, \square \}$. Then, there exists another TM $M^{'}$ which also computes $f$ but which has a single work tape and which uses the standard alphabet $\{ 0,1,\triangle,\square \}$. Moreover, if $M$ runs in time $T_{M}(n)$ on inputs of size $n$, then $M^{'}$ runs in time at most $O(T_{M}(n)^2 * \log(k))$
