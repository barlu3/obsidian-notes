### TMs with Large Alphabets

$$
\text{Let M be a TM with alphabet } \{ 0, 1, 2, 3, \delta, \gamma \}
$$
Then, we can use an original TM with binary alphabet to represent M; transpose M's alphabet to binary 
$$
\{ 0, 1, 2, 3, \delta, \gamma \}_{M} \equiv \{ 00, 01, 10, 11, 101, 110 \}_{M^{'}}
$$

### TMs with Many Work Tapes

$$
 \text{Let M be a TM with work tapes } \{ a, a, a, a \} \text{ and } \{ b, b, b, b \} 
$$
We can fit both work tapes onto a single work tape and map onto the single tape with prime and double prime pointers. Therefore, TMs with multiple work tapes do not add computation power
