### Phase 0 

- In the beginning, OS is just runtime libraries (routines)
	- piece of code used/sharable by many programs
	- abstraction: reuse magic to talk to physical device
	- avoid bugs
- user scheduled an exclusive time where they would use the machine
- UI was switches and lights, eventually punched tape and cards
	- less bugs as a result of the switch

### Phase 1 (batch systems)

- Computers expensive; people cheap
	- use computers efficiently - move people away from machine
- OS became a program loader
	- loads a job, runs it, outputs result, moves on to next job
	- more efficient use of hardware but harder to debug
		- less bugs doe

### Advances in OS in this period

- SPOOLING/Multiprogramming
	- Simultaneous Peripheral Operations On-Line (SPOOL)
		- Non-blocking tasks
		- copy document to printer buffer so printer can work while CPU moves to something else
	- Hardware provided memory support
	- Scheduling
	- OS must manage interactions between concurrent things

### Phase 1 (problems)

- Utilization is low (one job at a time)
- No protection between jobs
- Scheduling
- Coordinating concurrent activities
- People time being wasted
- OS didn't really work

### Phase 2: 1970s

- Computers and people are expensive
	- Help people be mroe productive then
- Interactive time-sharing: let many people use the same machine at the same time
- Emergence of minicomputers
	- Cheap terminals
- Persistence allows data online on fancy file systems

### Unix

- Ken Thompson and Dennis Richie built a system designed by programmers for programmers
	- Text editor, assembler, interpreter, compiler, etc.
- Originally in assembly and rewritten in C
	- they defend the decision 
	- portable operating systems
- Berkely added support for virtual memory for the VAX
	- Unix BSD
- DARPA selected UNIX as its networking paltform in ARPAnet
- Unix became commercial
	- Linux was invented by Linus Torvald

### Phase 3: 1980s

- Computers are cheap, people expensive
	- Put a computer in each terminal
	- CP/M from DEC first personal computer OS processors
	- IBM needed software for their PCs, but CP/M was behind schedule
	- Approached Bill Gates to see if he can build one
	- Gates approached Seattle computer products, bought 86-DOS and created MS-DOS
	- OS becomes subroutine library and command executive

### Phase 4: 1990s to 2020

- All about connectivity
- Enables parallelism but performance is not goal
- Goal is communication/sharing/power consumption/...
	- Requires high speed comms
	- We want to share data not hardware
- Networked applications drive everything
	- Web, email, messaging, social networks
	- Chromebook
